어플리케이션에 적합한 드라이브 찾기

iC7-Automation은 설치 환경과 용량에 따라 3가지 타입으로 제공됩니다.

Type 1
AC 드라이브 (주파수 변환기)
3 × 380-500 V AC  |  0.37 – 710 kW
벽면 장착, 캐비닛 장착 또는 독립형 설치에 최적화. 가장 광범위한 용량 범위로 다양한 산업 현장에 유연하게 적용 가능합니다.
Type 2
공냉식 시스템 모듈
3 × 380-500 V AC  |  200 – 2,700 kW
업계 최고의 전력 밀도. 빠른 통합과 캐비닛 공간 활용에 최적화되어 대용량 설비에 경제적인 솔루션을 제공합니다.
Type 3
판넬형 드라이브 (Enclosed Drive)
3 × 380-500 V AC  |  200 – 900 kW
신속한 시스템 통합과 향상된 사용자 안전을 위해 바로 실행할 수 있는 완전한 캐비닛. 설치 공기 단축과 안전성을 동시에 확보합니다.

핵심 기능 및 장점

🎯
최고의 모터 제어 정밀성
개회로·폐회로 모두에서 저속에서도 우수한 샤프트 성능 구현. 정지 상태에서 자동 모터 최적화(AMO)로 빠른 시운전이 가능합니다.
🔒
설계 기반 보안 · 산업용 IoT
시장을 선도하는 하드웨어 기반 보호로 무단 액세스 차단. 보안 칩으로 엔드투엔드 암호화 데이터 전송을 보장합니다.
🛡️
STO SIL3 / PLe 표준 내장
Safe Torque-Off(STO) SIL3 및 성능 레벨 e(PLe)를 기본 제공. 별도 안전 장치 없이 최고 수준의 안전 기능을 즉시 활용합니다.
🌐
통합 이중 Ethernet · 다중 필드버스
이중 Ethernet 포트와 다중 필드버스 프로토콜을 기본 탑재. 별도 통신 옵션 없이 PROFINET, EtherNet/IP 등 유연한 연결이 가능합니다.
📦
초소형 설계 · 후면 공기 유로 냉각
업계 최고의 전력 밀도로 설치 공간과 냉각 비용을 절감. 후면부 공기 유로 냉각으로 캐비닛 열 관리를 효율화합니다.
⚡
모듈형 확장 · 전력 유닛 병렬화
모듈형 제어 플랫폼으로 필요에 맞게 기능 확장 가능. 밸런싱 필터 없이 전력 유닛 병렬화로 전력 용량을 유연하게 증가시킵니다.
전체 기능 요약
  • 초소형 설계로 공간 절약 및 냉각 비용 절감
  • 통합 이중 Ethernet 포트 (다중 필드버스 프로토콜)
  • STO SIL3 / 성능 레벨 e(PLe) 기본 제공
  • 다수의 내장형 센서로 제어 정확성 개선
  • 가상 모델 지원으로 개발 프로젝트 가속화
  • 내장형 필터로 통합 비용 절감
  • 밸런싱 필터 없이 전력 유닛 병렬화
  • 모터 케이블 제거 없이 전력 유닛 교체 가능
  • 모듈형 확장 가능한 컨트롤 컨셉트
  • 후면부 공기 유로 냉각으로 효율적 열 관리
  • 자동 모터 최적화(AMO)로 빠른 시운전
  • 선택 가능한 통신 프로토콜 지원

어플리케이션 소프트웨어

두 가지 내장 애플리케이션이 고급 자동 모터 최적화와 고성능 모터 제어를 제공합니다.

⚙️  Industrial Application
고급 자동 튜닝을 통한 고성능 속도 및 토크 제어. 개회로·폐회로 모두 지원하며 복잡한 산업용 프로세스에 최적화됩니다.
🔄  Motion Application
단일 축 선형·회전 위치 제어 및 동기화 작업에 최적. 정밀한 움직임 제어가 필요한 고도화된 자동화 설비에 활성화하여 사용합니다.
